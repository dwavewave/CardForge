# Art direction — CardForge Arcane Codex

Reference: composite PNG already placed by user in existing CardForge `reference/` folder. Inspect that file in situ.

- Visual fidelity: gold/brass relief filigree, ruby enamel, dark navy panels, dragon wings, sword motif, rune/gem motif, subtle parchment texture. The uploaded reference contains several **independently selectable** frame styles and an elaborate symmetrical dragon/compass back.
- Frame choice is independent of card type. Spell, NPC RP, Plot Point, Monster and Custom can each use ANY frame.
- Use ornate borders as image assets/layers, not CSS approximations; prepare aligned 63:88 variants without distortion. Account for the original composite's uneven frame sizes and possible resolution constraints.
- Keep a generous inner safe area. Cinzel headings, legible body face, readable tag icons and labels. Avoid sacrificing content legibility for decoration.
- Two reverse modes: matching framed information back; full decorative dragon/compass back for otherwise empty cards or when selected.
- Optional user-imported illustrations, never mandatory. No forced category-to-frame mapping.
- Include print proofs with realistic dense content; show warning if minimum text size is breached.
